# My Portfolio (Next.js)

Scaffold Next.js (TypeScript) minimal pour un portfolio de développeur.

Installation

1. Installer les dépendances:

```powershell
npm install
```

2. Lancer en développement:

```powershell
npm run dev
```

Structure créée

- `pages/` : `index`, `about`, `projects`, `contact`, `_app`
- `components/` : `Layout`, `Header`, `Footer`, `ProjectCard`
- `styles/` : `globals.css` (Tailwind)
- `tailwind.config.js`, `postcss.config.js`, `tsconfig.json`, `next.config.js`, `package.json`

Notes

- Ce dépôt est un squelette. Personnalisez les contenus, ajoutez images dans `public/` et ajustez le design.
- Après `npm install`, vous pouvez aussi installer d'autres outils (formulaires, CMS, analytics).
